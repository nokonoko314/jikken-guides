      JDKとNetBeansを用意する

      資料2「開発環境NetBeans」

      演習室のPCには入っています。自分のPCで作業する場合は、次で入れられます。

      winget install EclipseAdoptium.Temurin.21.JDK
winget install Apache.NetBeans
java -version

      スライドの「Javaでの実行までの流れ」のとおり、javac（コンパイラ）が .java を .class（中間コード）にし、java（仮想マシン）がそれを実行します。NetBeansは、この2つを「実行」ボタン1つでまとめて行ってくれる道具です。

      プロジェクトを作る

      資料2「最初のプログラムを作ってみよう！」
      1. メニュー「ファイル」→「新規プロジェクト」
      2. カテゴリ「Java」（新しい版では「Java with Ant」）、プロジェクト「Javaアプリケーション」→ 次へ
      3. プロジェクト名：4EJ_Kadai1_(名列番号)、主クラス名：Sample1 → 完了

      Javaでは、Sample1.java の中に public class Sample1 がないとエラーになります（ファイル名とpublicクラス名を一致させる決まり）。大文字・小文字も区別します。NetBeansで作ればここは自動でそろいます。

      3

      Sample1 を動かして、エラーを直す

      資料2「先ほどのプログラムを作ろう」「エラーになる場合」「デバッグ」

      スライドの Sample1 を打ち込むと、わざとエラーになる行があります。NetBeansでは、エラーの行に赤い印が出て、マウスを乗せると理由が表示されます。

      考えることヒント
      どの行がエラーかif の条件の行。Javaの if には、true/false（boolean）になる式しか書けない
      = は何をする記号かJavaでは「代入」。比べるときの記号は別にある（C言語と同じ）
      何と比べればよいか表示する文は「評価『優』の教科数」。優は何点以上か、を考えて比較の記号を選ぶ

      直したら「実行」（▶）で動かし、画面下の「出力」に結果が出ることを確かめます。次に、行番号をクリックしてブレークポイント（赤い四角）を置き、「デバッグ」で実行すると、その行で止まって変数の値を確認できます。

      C言語の if (value = n) はコンパイルが通ってしまい、気づきにくいバグになります。Javaは if に boolean しか書けないので、コンパイルの時点で気づけます。この違いは、Javaの「型がしっかりしている」という特徴の例です。

      4

      ArrayList を使ってみる

      資料3「ArrayListクラスを使ってみよう」「どんなメソッドがあるのか？」

      スライドのリストのプログラムを打つと、1行目の ArrayList が赤くなります。電球マークから「インポートを追加」を選ぶと、ファイルの先頭に import java.util.ArrayList; が入って直ります（Ctrl+Shift+I でまとめて追加もできます）。

      メソッドしていること
      add(値) / addAll(別のリスト)末尾に1つ追加／別のリストの中身をまとめて追加
      get(番号) / set(番号, 値)取り出す（消えない）／書き換える
      remove / size() / contains(値)削除／要素数／含まれているか
      Collections.sort(リスト)小さい順に並べ替える（import java.util.Collections;）

      スライドの ArrayList mylist = new ArrayList(); は古い書き方で、警告が出ることがあります。今は ArrayList<Integer> mylist = new ArrayList<>(); のように、中に入れる型を書くのが普通です。こうしておくと、並べ替えや取り出しで型の間違いが起きません。

      5

      課題1：2つのリストを結合して並べる

      スライド「今日の課題」／資料3「課題の解決方針」

      スライドの「上手なプログラムの秘訣：いろいろ新しいものを作らない」のとおり、結合も並べ替えも、自分で関数を書かずにArrayListとCollectionsの機能で済ませるのがこの課題のねらいです。

      1. 数学用と化学用に、ArrayListを2つ作って得点を入れる
      2. 結合用のリストを作り、2つの中身をまとめて入れる
      3. 並べ替えて、表示する

      結果は 9＋7＝16個になります。同じ点数（例：78、92）が両方にあっても、リストは重複をそのまま残します。重複をなくしたい場合に使う入れ物（Set）との違いを調べると、発展の話題になります。

      課題2：Mapで名前から得点を探す

      スライド「今日の課題」名前と得点のリストからの検索
      やること使えるもの
      名前→得点の組を入れるHashMap<String, Integer> と put(名前, 得点)
      名前の一覧を取り出すmap.keySet()（これをArrayListに入れ直すと並べ替えられる）
      アルファベット順に並べるCollections.sort(名前のリスト)。文字列は辞書順に並ぶ
      その順に得点を表示拡張for文で名前を1つずつ取り出し、map.get(名前)

      HashMapは、入れた順も名前順も覚えていません。そのため「名前を取り出して並べ替えてから探す」という手順が必要になります。最初から名前順で持つ TreeMap もあり、両者の違いを調べると第11回（探索とデータ構造）の予習になります。

      うまくいかないとき

      class Sample1 is public, should be declared in a file named …ファイル名とpublicクラス名が違う
      「出力」に何も出ない実行したのが別のプロジェクト。プロジェクトを右クリック →「実行」
      IndexOutOfBoundsExceptionget() の番号がリストの大きさを超えている。番号は0から
