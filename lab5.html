      画像を読み込んで、結果を保存する

      スライド「画像処理の基本」

      LMSの画像を作業用フォルダに置き、まず「読み込めたか」を確かめます。

      import cv2
img = cv2.imread("hiyoko.png")
if img is None:
    raise SystemExit("読み込めませんでした（ファイル名・場所を確認）")
print(img.shape)          # (高さ, 幅, 3)
cv2.imwrite("out.png", img)
      (366, 512, 3)                     ← 高さ366・幅512・色3チャンネル（画像によって違う）
（同じフォルダに out.png ができる。読めなかったときは、次の行と「読み込めませんでした」が出る）
[ WARN:0@0.010] global loadsave.cpp:278 findDecoder imread_('hiyoko.png'): can't open/read file: check file path/integrity
      知っておくこと内容
      失敗してもエラーにならないimread は読めないとき None を返すだけ。次の行で分かりにくいエラーになるので、上のように確かめる
      日本語のパスは読めないフォルダ名やファイル名に日本語が入っていると None になる。英数字だけの場所に置く
      色の順番はBGROpenCVは青・緑・赤の順。matplotlibで表示すると色が入れ替わって見えるので、cv2.cvtColor(img, cv2.COLOR_BGR2RGB) してから表示する
      座標は (x, y)、配列は [y, x]関数に渡す座標は横・縦の順、img[y, x] で画素を取り出すときは縦・横の順

      処理の途中の画像（二値化した画像、マスク、輪郭を描いた画像）を毎回ファイルに保存しておくと、どこで思いどおりにならなかったかがすぐわかります。そのままレポートの図にも使えます。

      3

      二値化と、色で取り出す方法

      スライド「二値化」〜「OpenCVにおける画像の二値化」「二値化によるマスキング」

      ほとんどの課題は「調べたい物を白、それ以外を黒にした画像」を作るところから始まります。作り方は大きく3つです。

      方法関数向いている場面
      明るさで分けるcv2.threshold（グレースケールにしてから）背景と物の明るさがはっきり違う
      閾値を自動で決めるcv2.THRESH_BINARY + cv2.THRESH_OTSU（閾値には0を渡す）手で閾値を決めにくい。画像ごとに明るさが違う
      色の範囲で分けるcv2.inRange(画像, 下限, 上限)黄色いひよこ、青い背景など、色に特徴がある
       
      import numpy as np
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
lower = np.array([H下限, S下限, V下限], np.uint8)
upper = np.array([H上限, S上限, V上限], np.uint8)
mask = cv2.inRange(hsv, lower, upper)   # 範囲内が白(255)になる
print(hsv[120, 200])                    # 画素(x=200, y=120)のHSVを見る
      [ 27 214 243]                     ← H・S・V の順。この例は黄色（Hが20〜35あたり）。何点か見て範囲を決める

      スライドの例はBGRのまま範囲を指定していますが、色で分けるときはHSV（色相・彩度・明度）に変換したほうが、影や明るさの違いに強くなります。OpenCVの色相Hは0〜179の範囲（360度の半分）なので、黄色はおよそ20〜35あたりです。実際の値は、画像の中の画素を hsv[y, x] で何点か表示して決めるのが確実です。

      白黒が逆になったときは THRESH_BINARY_INV を使うか、cv2.bitwise_not で反転します。次の輪郭抽出は「黒い背景の中の白い物」を探すので、物が白になっているかを必ず確認してください。

      4

      輪郭を取り出して、数える・測る

      スライド「輪郭抽出」〜「OpenCVにおける外接矩形」
      contours, hierarchy = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print(len(contours))
      57                                ← 見つかった輪郭の数（ゴミも含む）。この数を面積で絞り込んでいく

      スライド（3.4.2）の書き方 img_cont, contours, hierarchy = … のままだと、4.x 以降（5.0 も同じ）では ValueError: not enough values to unpack (expected 3, got 2) になります。4.x 以降は最初の戻り値（輪郭画像）がなくなり、2つだけ返ります。

      関数わかること
      cv2.contourArea(c)輪郭の面積（画素数）。小さすぎるもの・大きすぎるものを除くのに使う
      cv2.boundingRect(c)傾きを考えない外接矩形 x, y, w, h
      cv2.minAreaRect(c)傾きを考えた外接矩形 ((中心x, 中心y), (幅, 高さ), 角度)
      cv2.drawContours(img, contours, -1, (0,0,255), 2)見つけた輪郭を赤で描く（-1は全部）。確認用

      len(contours) をそのまま答えにすると、ゴミのような小さな点まで1個と数えてしまいます。面積の一覧を表示して、物1個ぶんの面積がどのくらいかを見てから、「面積がこれ以上のものだけ数える」という条件を付けるのが基本の形です。

      5

      ノイズを取る（フィルタとモルフォロジー）

      スライド「フィルタリング」〜「OpenCVのフィルタ」
      処理関数効果
      平均化・ぼかしcv2.blur、cv2.GaussianBlur、スライドの filter2D細かいざらつきを弱める。輪郭もぼける
      メディアンcv2.medianBlur(img, 5)点状のノイズ（ごま塩ノイズ）に特に強い。輪郭が比較的残る
      オープニングcv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)二値画像の白い小さな点を消す
      クロージングcv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)白い物の中の黒い穴を埋める

      「二値化の前にぼかす」「二値化の後にオープニング」のどちらでも効果があります。どの順で何をしたかで結果が変わるので、試した組み合わせと結果を表にしておくと、考察で「なぜこの方法にしたか」を説明できます。カーネル（np.ones((5,5), np.uint8) など）を大きくするほど強く効きますが、物そのものも削れます。

      6

      基本1：ひよこの数を数える

      スライド「基本課題1」

      スライドのキーワードの順（色抽出 → 二値化／マスク → ノイズ除去 → 輪郭検出 → 輪郭描画で確認）が、そのまま処理の流れになります。

      1. ひよこの黄色をHSVの範囲で取り出す（手順3）
      2. オープニングで小さな点を消し、クロージングで目やくちばしの穴を埋める（手順5）
      3. 輪郭を取り、面積で小さいものを除いて数える（手順4）
      4. 数えた輪郭を元の画像に描いて保存し、目で見て合っているか確かめる

      スライドに「大きさや色の違いを認識」とあるように、ひよこには大きさや色の違うものが混ざっています。ひよこどうしがくっついていると、2羽が1つの輪郭になります。面積が「1羽ぶんの面積」の何倍かで数を推定する、くっついた部分を削ってから数える（収縮 cv2.erode や距離変換 cv2.distanceTransform）などの工夫が考えられます。どこで数え間違えたかを画像で示すと、よい考察になります。

      7

      基本2：錠剤のOK・NGを判定する

      スライド「基本課題2」

      錠剤を数えて、8個ならOKと表示します。数え方は基本1と同じ考え方です。

      • 錠剤は白っぽく、シートの銀色とは明るさや彩度が違う。グレースケールの明るさで分けるか、HSVの彩度（S）で分けるかを、両方試して比べる
      • 錠剤が抜けた穴（空のポケット）も明るく写ることがある。面積や形（円に近いか）で錠剤と区別する
      • OK画像とNG画像の両方で同じプログラムを動かし、どちらも正しく判定できることを確かめる

      形が円に近いかは「円形度」＝ 4π×面積 ÷ 周囲長² で表せます（周囲長は cv2.arcLength(c, True)）。円なら1に近く、細長いほど小さくなります。

      8

      基本3：ギアの長さを測る

      スライド「基本課題3」

      キーワードは「二値化、輪郭検出、外接矩形」です。ギアの輪郭を1つ取り出し、外接矩形の幅か高さ（スライドの矢印の向き）を出力します。

      • ギアが斜めに置かれているなら、boundingRect ではなく minAreaRect を使う
      • いちばん大きい輪郭がギア、と決めると、ゴミを拾いにくい（max(contours, key=cv2.contourArea)）

      スライドの問い「実際の長さにするにはどうしたらいいか？」への答えは、長さのわかっている物（定規やマーカー）を同じ距離で一緒に写し、1ピクセルが何mmかを求めることです。カメラと物の距離が変わると倍率が変わる、レンズのゆがみで端ほどずれる、といった誤差の原因も考察に書けます。

      9

      基本4：ノイズのある画像で太さを判定する

      スライド「基本課題4」
      1. まずノイズを取る（手順5のメディアンが効きやすい）
      2. 二値化して物の輪郭を取り、太さを測る
      3. 「何ピクセルから何ピクセルまでならOK」という範囲を自分で決め、その中かを判定する

      太さの測り方はいくつかあります。minAreaRect の幅と高さの短いほうを使う方法、物を横切る1列の白い画素を数える方法、面積 ÷ 長さで平均の太さを出す方法などです。物の太さが場所によって違う場合は、どの測り方が「太さ」として適切かを考えて、選んだ理由をレポートに書きます。OK画像とNG画像の値を並べて、その間に範囲を置いた根拠を示すと説得力が出ます。

      10

      基本5：箱のラベルの有無を判定する

      スライド「基本課題5」「マスク処理」〜「自動検出によるマスキング」

      スライドの手順（箱の範囲を検出 → 箱以外をマスク → 適切な場所にラベルがあるか判定 → 傾き補正）のとおりに進めます。

      段階ヒント
      箱の範囲箱の色で二値化し、いちばん大きい輪郭を箱とする
      マスク黒い画像に箱の輪郭を白で塗りつぶし（drawContours の太さに -1）、cv2.bitwise_and で箱だけを残す
      ラベルの判定箱の中でラベルがあるはずの場所（箱の大きさに対する割合で決める）を切り出し、ラベルの色の画素がどれだけあるかの割合で判定する
      傾きの補正minAreaRect の角度で、cv2.getRotationMatrix2D と cv2.warpAffine を使って回転させる

      ラベルの場所を「左から100ピクセル」のように決めると、箱の位置や大きさが変わった画像で外れます。箱の外接矩形を基準に「箱の幅の何割の位置」と決めると、どの画像でも同じ考え方で使えます。

      minAreaRect が返す角度の決まりは OpenCV のバージョンで何度か変わっています。傾いていない長方形でも、版によって 90 度や -90 度と出ることがあります（5.0 で試すと -90 度でした）。角度を表示してみて、思った向きと90度ずれていたら、幅と高さを入れ替えて考えます。

      発展課題の手がかり

      スライド「発展課題1〜3」「任意の発展課題」
      課題手がかり
      ラベルの文字文字認識（OCR）は Tesseract と pytesseract で試せる（Tesseract本体を別に入れる必要がある）。読む範囲を切り出し、拡大・二値化してから渡すと精度が上がる。0 と O、1 と l の取り違えは、使う文字を英大文字と数字に絞ると減る
      コネクタの抜け上から3番目の位置を切り出し、コネクタの色の画素の割合で有無を判定。本数は基本1と同じく輪郭を数える
      圧力計文字盤の円は cv2.HoughCircles、針の直線は cv2.HoughLinesP で見つけられる。円の中心から見た針の角度を、目盛りの角度と比べて値に直す
      任意スライドの例（農産物のサイズ、部品の形状検査）のように、基本課題の組み合わせで「自動で判定する」ものが望ましい

      うまくいかないとき

      症状原因と対処
      ModuleNotFoundError: No module named 'cv2'仮想環境が有効になっていない、または別のPythonで実行している。.\.venv\Scripts\Activate.ps1 をしてから実行。入れるパッケージ名は opencv-python
      'NoneType' object has no attribute 'shape'画像が読めていない。ファイル名、置き場所、パスに日本語がないかを確認
      not enough values to unpack (expected 3, got 2)スライド（3.4.2）の findContours の書き方。4.x 以降は戻り値は2つ
      輪郭が1つ（画像全体）しか取れない白黒が逆。物が白、背景が黒になるように反転する
      数が多すぎる小さなノイズまで数えている。面積で除くか、オープニングで消す
      数が少なすぎる物どうしがくっついて1つになっている。面積から推定するか、収縮で切り離す
      imshow の窓がすぐ消える／固まるcv2.waitKey(0) を後ろに書く。閉じるときは窓を選んでキーを押す
      matplotlib で色がおかしいBGRのまま表示している。RGBに変換してから表示する
