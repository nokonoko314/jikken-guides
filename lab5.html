    この回でやることOpenCVで、ひよこの数、錠剤のOK・NG、ギアの長さ、ノイズのある物の太さ、箱のラベルの有無を、画像から自動で求める。二値化・輪郭抽出・フィルタ・マスク処理を組み合わせる。

      59 KBダウンロード

    スライドと課題の画像はLMSから取得してください（スライドは OpenCV 3.4.2 の書き方です。このページは今 pip で入る 5.0 に合わせています）。上の zip はこのページ用に作った手本で、中の見本画像も授業の画像ではありません。このページは、その内容を自分用に解説したものです。

    手順の一覧

      この手順書の使い方

      • OpenCV（Python）で画像を処理し、「ひよこの数を数える」「錠剤がそろっているか判定する」など、画像から自動で数えたり判定したりする回です。レポート③の対象です。
      • 手順2〜6に、基本課題1〜5の手本のプログラムがあります。「次へ」を押すと1ステップずつ進み、光っている行が何をしているか、どんな関数か、画像がどう変わるかが順に出ます。キーボードの ← → でも動きます。
      • 画像の上の黄色いラベルと矢印は、その行で注目する場所です。コードの中で黄色の下線が付いた所は、その行でいちばん大事な数や指定です。
      • 「この行を深掘りする質問」を開いて「コピー」を押すと、その行のコード付きの質問文がコピーされます。Claude などに貼り付けて聞けます。
      • 右側に出る画像は、説明のために作った見本の絵です。面積や長さの数字も見本でのものです。スライドの画像で動かした結果は、各手順の下に書いてあります。
      • プログラムのファイル名（hiyoko.png など）は仮のものです。LMSから取った画像の名前に合わせて cv2.imread("…") の中を書き換えてください。
      • 手本は答えの一例です。ガイダンスのとおり、他人のプログラムをそのまま出すと評定が0点になります。各行を自分の言葉で説明できるようにしてから使ってください。

      基本課題4：ノイズのある画像で太さを判定する

      スライド「基本課題4」

      やること：黒い点（ノイズ）がある画像で、黒い棒の太さを測り、決めた範囲に入っているか判定します。

      考え方：点は棒より小さいので、「点より大きく、棒より小さい四角」でオープニングをして点だけを消します。残った棒を囲む長方形の高さが太さです。

      発展課題の手がかり

      スライド「発展課題1〜3」「任意の発展課題」
      課題手がかり
      ラベルの文字文字認識（OCR）は Tesseract と pytesseract で試せる（Tesseract本体を別に入れる必要がある）。読む範囲を切り出し、拡大・二値化してから渡すと精度が上がる。0 と O、1 と l の取り違えは、使う文字を英大文字と数字に絞ると減る
      コネクタの抜け上から3番目の位置を切り出し、コネクタの色の画素の割合で有無を判定。本数は基本1と同じく輪郭を数える
      圧力計文字盤の円は cv2.HoughCircles、針の直線は cv2.HoughLinesP で見つけられる。円の中心から見た針の角度を、目盛りの角度と比べて値に直す
      任意スライドの例（農産物のサイズ、部品の形状検査）のように、基本課題の組み合わせで「自動で判定する」ものが望ましい

      うまくいかないとき

      症状原因と対処
      ModuleNotFoundError: No module named 'cv2'仮想環境が有効になっていない、または別のPythonで実行している。.\.venv\Scripts\Activate.ps1 をしてから実行。入れるパッケージ名は opencv-python
      'NoneType' object has no attribute 'shape'画像が読めていない。ファイル名、置き場所、パスに日本語がないかを確認
      not enough values to unpack (expected 3, got 2)スライド（3.4.2）の findContours の書き方。4.x 以降は戻り値は2つ
      輪郭が1つ（画像全体）しか取れない白黒が逆。物が白、背景が黒になるように反転する
      手本を動かしても数が合わないLMSの画像は、スライドの画像と大きさが違うことがある。for の中に print(area) を足して面積を表示し、面積のしきい値（3000 や 1000）を決め直す。色の範囲は print(hsv[y, x]) で画素の値を見て決める
      数が多すぎる小さなノイズまで数えている。面積で除くか、オープニングで消す
      数が少なすぎる物どうしがくっついて1つになっている。面積から推定するか、収縮で切り離す
      imshow の窓がすぐ消える／固まるcv2.waitKey(0) を後ろに書く。閉じるときは窓を選んでキーを押す
      matplotlib で色がおかしいBGRのまま表示している。RGBに変換してから表示する
