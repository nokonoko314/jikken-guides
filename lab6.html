      開発環境を用意する

      補足
      java -version
winget install EclipseAdoptium.Temurin.21.JDK
winget install Apache.NetBeans

      1行目でバージョンが出れば、2行目は不要です。NetBeansには、部品をマウスで並べて画面を作れるGUIビルダーがあります（新規作成 →「Swing GUIフォーム」→「JFrameフォーム」）。手で書く場合とビルダーで作る場合で、画面の作り方は違いますが、イベント処理の考え方は同じです。

      Pythonで作る場合、TkinterはPythonに最初から入っています。python -c "import tkinter; tkinter._test()" で小さな窓が出れば使えます。

      2

      CSVの成績データを読み込む

      スライド「本日の課題」プログラムの機能

      データファイルは別途配布（LMS）です。中身は、第9回のスライドにある次のような表をCSVにしたものと考えられます。届いたら、まずメモ帳で開いて、1行目が見出しか、区切りがカンマかを確かめます。

      Number,Name,Score1,Score2,Score3,Score4
1,Michael,75,86,89,31
2,Emma,74,63,70,48
      やることJavaで使えるもの
      全部の行を読むFiles.readAllLines(Path.of("ファイル名"))
      見出し行を飛ばす読んだリストの0番目を使わない（ループを1から始める）
      1行を項目に分けるline.split(",")
      点数を数にするInteger.parseInt()
      ファイルが見つからない（NoSuchFileException）NetBeansで実行すると、プログラムはプロジェクトのフォルダ（src の1つ上）を基準にファイルを探します。CSVはそこに置いてください。日本語が文字化けする場合は、CSVの文字コード（Shift_JIS か UTF-8 か）を確認し、読むときに指定します。
      3

      データの入れ物を決める（List か Map）

      スライド「本日の課題」List または Map の構造で保存
      入れ物名前で探すとき向いている場面
      ArrayList先頭から1人ずつ名前を比べる全員を順に見る処理（平均点N点以上の人を探す、など）
      HashMap<String, …>map.get("Michael") で一発で取り出せる名前をキーにした検索（この課題の基本）

      1人分の成績を、第9回で作る「学生1人を表すクラス」のようにまとめておくと、表示や応用課題が楽になります。どちらを選んだか、その理由を説明できるようにしておくと、報告で話せます。

      map.get() は、見つからないときに null を返します。手順6の「見つからなかった場合」の判定に、これをそのまま使えます。

      ボタンにイベント処理を付ける

      スライド「目次」イベント処理

      GUIのプログラムは、上から順に一度だけ動いて終わるのではなく、「ボタンが押された」などの出来事（イベント）が起きるのを待ち、起きたら決めておいた処理を実行する形で動きます。これをイベント駆動といいます。

      searchButton.addActionListener(e -> {
    String name = nameField.getText();   // 入力された文字を取り出す
    // ここで検索して、結果をダイアログに出す
});
      def on_search():
    name = name_entry.get()   # 入力された文字を取り出す
    # ここで検索して、結果をダイアログに出す

Button(root, text="検索", command=on_search)

      「入力内容クリア」は、入力欄を空にするだけです（Swingは setText("")、Tkinterは delete(0, END)）。

      GUIビルダーでは、ボタンをダブルクリックすると、押されたときに呼ばれるメソッドが自動で作られます。第3回のスライドの「匿名クラス」「ラムダ式」は、まさにこの書き方のためのものです。

      6

      結果をダイアログで表示する

      スライド「課題のGUIイメージ」検索すると新しい窓が開く
      方法特徴
      JOptionPane.showMessageDialog(this, 文字列)1行で出せる。まず動かすならこれ。見つからなかったときの知らせにも使える
      JDialog を自分で作るスライドの画面のように、表（国語・数学・英語・専門）と「閉じる」ボタンを並べられる。JTable を使うと表が作りやすい

      まず JOptionPane で「見つかった・見つからなかった」が正しく出ることを確かめてから、余裕があれば JDialog で見た目を整える、という順番がおすすめです。

      名前の前後に空白が入っていると見つかりません。入力を trim() してから探すと安全です。大文字・小文字を区別しないで探したい場合は、キーを小文字にそろえて保存する方法があります。

      応用：検索方法を増やす（必須ではない）

      スライド「課題の応用例」
      部品Swing使いどころ
      メニューJMenuBar、JMenu、JMenuItem「操作 → 終了」など
      ラジオボタンJRadioButton と ButtonGroup「氏名で検索」「平均点で検索」の切り替え。ButtonGroupに入れると1つしか選べなくなる
      コンボボックスJComboBox平均点の選択や、名前の候補を一覧から選ぶ
      状態を表示するラベルJLabelスライドの「System Message」。ファイルが開けたかを表示する

      「氏名は先頭文字だけでも良い」は startsWith()、「平均点N点以上」は全員を順に見て条件に合う人を集める処理です。複数人が見つかる場合の表示方法も考える必要があります。

      !

      うまくいかないとき

      症状原因と対処
      NoSuchFileExceptionCSVの置き場所が違う。NetBeansではプロジェクトのフォルダに置く
      名前が文字化けする／見つからないCSVの文字コードと読み込み時の指定が違う。前後の空白や改行も確認
      ボタンを押しても何も起きないイベント処理が結びついていない（addActionListener を書き忘れ、別のボタンに付けている）
      窓を閉じてもプログラムが終わらないsetDefaultCloseOperation(JFrame.EXIT_ON_CLOSE) がない
      NumberFormatException見出し行を数にしようとしている。1行目を飛ばす
