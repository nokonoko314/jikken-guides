    クラスタリングの基礎

    実施日2026年12月22日（火）
    レポートレポート④　1/12（火）9:00 締切
    この回でやること100個ほどの点を、距離をもとに指定した数のまとまりに分けて色分け表示する。3つの方法で「クラスタ間の距離」の決め方を変え、結果の違いを比べる。

    配布資料

    スライド、点のデータ（CSV）、サンプルコード、動物データはLMSから取得してください（スライドの日付は2024年11月26日のままです）。このページは、その内容を自分用に解説したものです。

    手順の一覧

      この解説の使い方

      • 2次元の点（100個ほど）を、距離をもとにいくつかのまとまり（クラスタ）に分け、色分けして表示する回です。分け方を3通り試して、結果の違いを比べます。
      • レポート④の対象です。ここでは環境の準備、考え方、ヒントまでを書き、距離の計算や結合の処理そのものは書いていません。
      • スライドには「3時間目終了後にサンプルコードを配ります。まずは自分の力で作ってみましょう」とあります。手順4までは、サンプルがなくても考えられる内容です。

      1

      配られたデータの形を知る

      スライド「本日のデータセット」「2次元データについて」

      2次元データはLMSで配布されます。基準点の数Mと、ばらつき（標準偏差）を変えた組み合わせが用意されています。サンプルの Main.java が読む m3sd50.csv は、名前のとおり「基準点3つ・標準偏差50」のデータです。

      基準点の数 M点の数標準偏差
      210050 または 200
      39950 または 200
      4、5100100 または 300
      999100 または 300

      サンプルの DataReader は、CSVの1行目を見出しとして読み飛ばし、各行の2列目をx、3列目をyとして整数の点（java.awt.Point）にします。座標の範囲はおよそ0〜1000です。

      標準偏差が小さいデータは点が基準点の近くに固まるので、どの方法でもきれいに分かれやすく、大きいデータは塊どうしが重なるので、方法による違いが出やすくなります。違いを見るなら、同じMで標準偏差だけ違う2つを並べて比べるのがわかりやすいです。

      3

      階層的クラスタリングの流れをつかむ

      スライド「最短距離法」「最終的にどうなるの？」

      3つの方法は、どれも次の同じ流れで、違うのは「クラスタどうしの距離」の決め方だけです。

      1. はじめは、点1つ＝クラスタ1つ（100個のクラスタ）とする
      2. すべてのクラスタの組について距離を求め、いちばん近い組を見つける
      3. その2つを1つのクラスタにまとめる（クラスタが1つ減る）
      4. クラスタの数が、指定した数になるまで2〜3を繰り返す

      スライドのとおり、最後まで続けると全部が1つになります。そのため「指定した個数になったらやめる」のが終わりの条件です。この「近いものから順にまとめていく」やり方を、凝集型の階層的クラスタリングと呼びます。原理の章で調べてまとめる際の手がかりになる言葉です。

      4

      3つの方法で「クラスタ間の距離」をどう決めるか

      スライド「クラスタリングの手法」「最長距離法」「重心法」
      方法クラスタAとBの距離結果の傾向
      最短距離法Aの点とBの点の組のうち、いちばん近い組の距離点が鎖のようにつながると、細長く1つにまとまりやすい（大きな塊1つと、外れた少数の点に分かれることがある）
      最長距離法Aの点とBの点の組のうち、いちばん遠い組の距離まとまりの大きさがそろいやすく、丸く小さめの塊になりやすい
      重心法Aの重心とBの重心の距離両者の中間的な結果になりやすい

      点どうしの距離は、ふつうのユークリッド距離（2点の差を2乗して足し、平方根をとったもの）で十分です。Javaでは Point 自体が距離を求める機能を持っているので、APIの説明（java.awt.Point の親クラス）で探してみてください。

      「いちばん近い組を探す」ときに、平方根をとる前の値（距離の2乗）で比べても、どちらが小さいかは変わりません。点の数が多いと計算量が効いてくるので、こうした工夫は考察に書ける材料になります。

      5

      Claster の距離のメソッドを書く

      サンプル Claster.java

      空になっているのは次の2つです。どちらも、最初に Double.MAX_VALUE（いちばん大きい値）を入れてから、小さい値が見つかるたびに置き換える形になっています。

      メソッド考え方のヒント
      getDistance(Point p)このクラスタの点を1つずつ取り出して p との距離を求め、いちばん小さいものを残す
      getDistance(Claster c)相手のクラスタの点を1つずつ取り出し、上のメソッドを使えば、最短距離法の距離になる

      最長距離法では「いちばん大きいものを残す」ので、初期値も比べ方も逆になります。重心法では、このクラスは重心（center）をすでに計算して持っているので、それを使えます。3つを切り替えられるように、メソッドを3つに分けるか、方法を表す引数を渡す形にしておくと、比較の実験が楽になります。

      最長距離法で、最初の値を Double.MAX_VALUE のままにして「大きいほうを残す」と、いつまでも初期値が残ってしまいます。最大を探すときの初期値は何にすべきか、考えてみてください。

      重心は、x / size のように整数どうしで割っているので、小数点以下が切り捨てられます。結果への影響はわずかですが、気づいたら考察で触れられます。

      Main の結合のループを書く

      サンプル Main.java「クラスタを結合 TODO ここは自分で書く」

      claster メソッドの中に、コメントアウトされた while の枠があります。その下にある「単にサイズ数に分けるだけのコード」は、表示を試すための仮のもので、本番では使わない部分です。

      1. main で呼ぶメソッドを、view_plot から claster に変える
      2. while の中で、すべての組（i番目とj番目、i < j）の距離を求め、いちばん近い組の番号を覚えておく
      3. その2つから新しいクラスタを作り（2つを受け取るコンストラクタが用意されています）、元の2つをリストから外して、新しいものを入れる
      4. ループを抜けたら、残ったクラスタの数だけ addPointList を呼んで表示する（仮のコードが使っている clistsep ではなく、結合後のリストを使う）

      リストから2つ外すとき、先に小さい番号を外すと、後ろの要素の番号が1つずつ前にずれます。大きい番号から先に外すと、この問題は起きません。

      クラスタの数（maxcount）は「ユーザが指定する」課題なので、固定の3ではなく、実行時に入力させるか、引数で渡せるようにしておくと要件を満たせます。

      100点から始めると、組の数は約5000、それを約100回繰り返すので、合わせて数十万回の距離計算になります。最短距離法と最長距離法ではクラスタの点どうしを全部比べるので、さらに多くなります。それでも一瞬で終わる規模ですが、点の数が増えるとどうなるかは考察の材料になります。

      3つの方法を比べて、結果を残す

      スライド「実験上の注意」二次元の点の分類結果は画像で示しましょう

      比較が見やすくなるように、条件をそろえて表にしておくとレポートが書きやすくなります。

      そろえること変えること
      同じデータファイル、同じクラスタ数（基準点の数Mに合わせるのが自然）方法（最短・最長・重心）
      同じ方法、同じクラスタ数標準偏差（小さいデータと大きいデータ）

      表示された画面は、Win+Shift+S で範囲を選んで画像として残せます。ファイル名に「データ名_方法_クラスタ数」を入れておくと、あとで混ざりません。

      データは基準点から作られているので「正解のまとまり」がわかっています。それぞれの方法の結果が正解にどれだけ近いか、どの方法がどんなデータで失敗したか（例：最短距離法で、1つの大きな塊と数点だけの塊に分かれた）を、理由とあわせて書くと考察になります。

      8

      発展：動物データと、別の手法

      スライド「本日の課題」発展課題／「時間が余った人は・・・」

      動物データ（Kaggle の Zoo Animal Classification、LMSで配布）は、1行が1種類の動物で、毛があるか・卵を産むか・脚の本数などの特徴が並んでいます。分類の答え（種類の番号）も付いています。

      • 点が2次元（x, y）ではなく、特徴の数だけの次元になるので、Point の代わりに数値の配列を持つクラスを用意する
      • 距離は、各特徴の差の2乗を全部足して平方根をとる（2次元の式の拡張）
      • 名前の列と答えの列は、距離の計算に入れない（答えを入れると、答えで分けることになってしまう）
      • 結果は、スライドのとおり「クラスタごとに動物名を並べた文字列」で示せばよい。付いている答えと比べると評価できる

      脚の本数（0〜8）だけ値の幅が大きく、ほかの特徴（0か1）より距離に強く効いてしまいます。スライドの「要素に重みづけして分類を最適化する」は、この偏りをどう直すかという話につながります。

      群平均法は、AとBの点のすべての組の距離の平均をクラスタ間の距離にする方法で、手順5のメソッドを1つ増やすだけで試せます。K-means法は考え方が違い、最初にK個の中心を決め、「各点を最も近い中心に割り当てる → 中心を割り当てた点の重心に動かす」を、変化がなくなるまで繰り返します。最初の中心の選び方で結果が変わることも、考察の材料になります。
